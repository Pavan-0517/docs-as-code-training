# Administration
 
Administrators can manage users, roles, and system settings.
 
## Manage users
 
Administrators can add, edit, deactivate, and delete users.
 
## Manage roles
 
Use roles to control access to product features.
 
## Manage system settings
 
System settings control application-wide behavior.

For troubleshooting, please refer [this guide](/docs/troubleshooting.md)
